# v7.36.1 — VRAM·성능 비교를 GPU 결과로 이동

VRAM–성능 프런티어는 온톨로지 비용과 관계없는 GPU 선택 결과입니다. 이제 `내 GPU로 모델 찾기`에서 GPU를 선택하면 빠른 추천 3개 다음에 차트와 VRAM별 추천표가 나타납니다.

- 선택한 GPU의 사용 가능 VRAM을 차트의 기준선으로 표시합니다.
- 같은 공개 벤치마크 안에서만 모델 품질과 Q4_K_M 예상 VRAM을 비교합니다.
- 전체 모델별 근거 표는 `전체 모델 탐색`의 벤치마크 시트에 그대로 남겨 상세 검증에 사용합니다.
- API 비용·온톨로지 구축 비용 등 별도 작업에서는 GPU 결과와 벤치마크 시트를 숨깁니다.
- 상단 고급 도구에서는 독립 온톨로지 비용 메뉴를 제거해 여러 모델 배치·API 비용·실측 벤치마크를 우선합니다. 기존 공유 URL은 계속 열립니다.
