# v7.36.0 — VRAM–성능 프런티어

`Q4_K_M · 4K context · 동시 요청 1 · llama.cpp` 기준으로 필요한 VRAM과 공개 벤치마크 점수를 한 화면에서 비교합니다.

- 동일한 공개 벤치마크 지표를 가진 모델끼리만 비교
- 8GB부터 128GB까지 최고 점수 모델과 차선 후보 표시
- 더 적은 VRAM으로 같거나 높은 점수를 내는 후보가 없는 프런티어 강조
- 선택한 GPU의 사용 가능 VRAM 기준선과 벤치마크 출처 연결
- 매주 모델 추가·삭제·점수·VRAM 추천 변화를 기록하는 자동 리포트

점수는 모델 제작자 또는 공식 보고서의 공개값이며, 평가 세부 조건은 다를 수 있습니다. 제품 화면에서 각 출처를 직접 확인할 수 있습니다.
