# v7.38.0 — 2026-09-30 카탈로그·API 요금 검토

낮은 VRAM과 Apple Silicon에서 비교할 만한 누락 모델·음성 모델부터 보강했습니다. 실제 GPU 프리셋은 151→158종(직접 입력 제외), 로컬 AI 모델은 332→347종, API 가격 항목은 9→13종입니다. 직접 입력까지 포함한 데이터 행 수 159를 GPU 수로 표시하던 집계도 정정했습니다. 이번 검토는 자체 GPU 실측을 새로 수행한 작업이 아닙니다.

Rubin/MI455X의 시스템 RAM 1024GB는 앱의 초기 호스트 설정이지 GPU 제품 사양이 아닙니다. 일반 소매 GPU처럼 메모리/대역폭으로 가격·전력을 만들어내지 않도록 `requiresSystemQuote`로 자동 구매 추천에서 제외합니다. 실제 서버·랙 구성, 공급 가능 시점, 전력, 가격은 공급사 확인이 필요합니다. 메모리 적합성 확인용 GPU 선택에는 남습니다.

계산기는 비캐시·비배치 텍스트 표준가를 사용합니다. 캐시 쓰기, 도구/검색, 오디오/이미지, 긴 컨텍스트 할증과 토크나이저 차이는 별도입니다. OpenAI는 272K 입력 토큰 초과 시 할증, Gemini Pro는 200K 초과 시 할증이 있습니다. Gemini 3.8 Flash는 2027-01-01부터 입력 1.50/출력 7.50/캐시 0.15로 공지되어 있으며 아직 미래 요금으로 계산하지 않습니다.

DeepSeek V4.1 Flash의 API 이름은 `deepseek-flash`이며 기본 비교는 피크 요금입니다. 오프피크 입력/출력/캐시는 0.15/0.60/0.003이고 피크는 평일 UTC 01–04시·06–10시(중국 공휴일 제외)입니다. 시간대별 할인은 자동 계산하지 않습니다. 로컬 계산 카탈로그 반영 보류와 별개로 공식 API 요금은 비교할 수 있습니다. Mistral의 OCR·음성 서비스는 페이지·분·문자 단위이므로 텍스트 토큰 가격 목록에 혼합하지 않았습니다.

## 확인했지만 이번 계산 카탈로그에는 보류한 항목

- [DeepSeek V4.1 Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash): 2026년 9월 신규 모델. CED·Engram 조건부 메모리·FP4 KV 압축을 사용해 기존 계산을 단순 적용하면 메모리 추정이 왜곡됩니다. 패킹된 I8/FP8 텐서 원소 수를 그대로 실제 파라미터로 사용하지 않았습니다. 런타임별 적재·오프로드·KV 정책 검증이 우선입니다.
- [GLM-5.3](https://huggingface.co/zai-org/GLM-5.3): 신규 대형 모델과 전용 라이선스·희소 어텐션을 확인했습니다. 총/활성 파라미터와 실제 메모리 근거 보강 후 반영합니다. 이미 있는 Flash의 출처는 공식 카드로 수정했습니다.
- [Qwen-Image-2.1](https://huggingface.co/Qwen/Qwen-Image-2.1), [FLUX.2 klein 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B), [LTX-2.5](https://huggingface.co/Lightricks/LTX-2.5): 최신 이미지·영상 계열을 확인했습니다. 텍스트 인코더·VAE·오프로드·스텝·프레임별 상주 메모리와 처리량 근거 없이 기존 모델의 숫자를 복사해 새 모델처럼 표시하지 않습니다.
