# v7.32.0 — 첫 방문·로딩 안정성·공개 소개 정리

일반 홈페이지 링크는 이전 GPU를 저장해 두었더라도 GPU 선택 화면에서 시작합니다.
최근 선택 GPU는 목록 첫 칸에서 직접 다시 선택할 수 있고, GPU가 지정된 공유 링크는 결과를 바로 엽니다.

- 실패한 지연 로딩 스크립트를 제거해 다음 클릭에서 재시도할 수 있게 했습니다.
- IntersectionObserver 미지원 환경에서도 숨겨진 벤치마크를 자동 로딩하지 않습니다.
- 테스트·개발 스크립트·패키지 잠금 파일을 Pages 배포물에서 제외했습니다. 동일 카탈로그 기준 배포 파일 합계 324,841바이트 감소(전송량·체감 속도 수치가 아님).
- 저장 GPU가 있는 재방문과 스크립트 재시도 회귀 검사를 추가했습니다.
- 공개 소개는 사용 예제, 계산 한계, 실측 제보 경로 중심으로 정리했습니다.

VRAM과 속도는 계획용 추정치입니다. 실제 GPU·런타임·양자화·컨텍스트를 함께 기록한 제보를 환영합니다.
