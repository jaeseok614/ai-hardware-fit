# AI Hardware Fit v7.37.0

모델을 먼저 선택한 뒤 GPU 3안을 비교하는 결과 화면에 가격·속도 프런티어를 추가했습니다.

- 실행 가능한 후보 전체를 가격과 예상 속도로 비교합니다.
- 더 싸면서 더 빠른 후보가 없는 GPU를 파레토 프런티어로 연결합니다.
- 최저 비용·균형 추천·최고 성능 카드를 차트에서도 강조합니다.
- GPU별 양자화 또는 정밀도와 가격·속도 근거를 함께 표시합니다.
- 국내 실가격, 출시가, 계산 가격과 실측 보정, 외부 벤치마크, 관련 실측, 계산 추정을 구분합니다.

이 차트는 상대 비교용 계획 자료입니다. 실제 결과는 드라이버, 런타임, 컨텍스트, 배치 크기, 발열과 지역별 시세에 따라 달라질 수 있습니다.
