# Weekly catalog verification — 2026-10-19

## Added

- LFM2.5-24B-A2B: official checkpoint 23,971,585,280 parameters, publisher active size 2.45B (not the rounded A2B name), 131,072-token context. No release date inferred from repository creation time.
- Official config: 40 layers, 30 short-convolution and 10 GQA, 8 KV heads, 64 head dimension, convolution cache length 3. KV estimate uses only the GQA layers and adds fixed BF16 convolution state; runtime allocator/activation overhead remains estimated separately. It is not a measured peak allocation.
- LiveClaw 48.09 is Liquid's vLLM evaluation, temperature 1.0, max output 8192. Not comparable to unrelated harnesses. No published throughput was imported as a local measurement; B300 aggregate throughput must not be treated as single-user decode speed.
- Official GGUF Q4_K_M, Q5_K_M, Q6_K, Q8_0 and F16 files verified. Unsupported quantizations produce a warning rather than a nonexistent download/Ollama tag. Use a current llama.cpp build supporting LFM2 MoE. Official card lists Transformers >=5.0.0; config was saved with 5.12.1. DSpark is coming soon and not recommended as available.
- License is Liquid's LFM license, not Apache/MIT; review checkpoint LICENSE for commercial terms.
