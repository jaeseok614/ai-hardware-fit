Floating-point batching can change generated text, including greedy output; do not promise byte-identical results.

## Official advanced launch recipe (not default)

Use a current llama.cpp build that implements `draft-dspark`, and separately verify available memory for target plus drafter:

```bash
llama-server -hf LiquidAI/LFM2.5-24B-A2B-GGUF:F16 \
  -hfd LiquidAI/LFM2.5-24B-A2B-DSpark-GGUF:F16 \
  --spec-type draft-dspark --spec-draft-n-max 9 --spec-draft-n-min 0 \
  -ngl 99 -ngld 99 -fa on
```

This is the publisher's recipe, not a locally executed hardware benchmark. The SGLang route requires LFM2-MoE DSpark/native config support (publisher links PRs #31041 and #43939); do not assume an arbitrary installed release supports it.
