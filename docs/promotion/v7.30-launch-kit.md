## 게시할 때 지킬 점

1. 첫 글에는 v7.30 첫 화면 캡처 한 장과 GPU→모델 질문 하나만 사용합니다.
2. “정확한 성능 보장”이 아니라 “계획용 추정치이며 실제 실행 검증 필요”라고 씁니다.
3. Star를 바로 요구하기보다 누락 GPU·실측값·계산 오차 제보를 먼저 요청합니다.
4. 후속 글은 RTX 3060 12GB처럼 하나의 실제 GPU 결과를 보여주고 같은 소개문을 반복하지 않습니다.
