## 배포 채널
GitHub Release와 저장소 Discussion으로 한 번 공개합니다. 이미 만들어 둔 소셜 미리보기와 결과 이미지를 재사용하고 버전마다 같은 외부 커뮤니티에 반복 게시하지 않습니다.
다른 커뮤니티 계정의 로그인·게시 가능 여부가 확인되지 않은 상태에서는 게시 완료라고 기록하지 않습니다.
